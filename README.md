# Outdraft for Windows

The first Windows build is being prepared. When available, download `Outdraft.exe` from the [Releases page](https://github.com/vshtykhnov/outdraft-downloads/releases).

Run it on Windows while Dota 2 is in borderless window or windowed mode. Restart Dota 2 once after the first run so it loads the overlay integration. New versions will appear on the Releases page; close the app and replace the old executable to update. The app requires an internet connection to its API.

This repository contains downloads only. The application source and API are kept in a separate private repository. GitHub's automatically generated source archives on each release contain only the files in this downloads repository.
