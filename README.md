# Outdraft for Windows

Download the latest [Outdraft.exe](https://github.com/vshtykhnov/outdraft-downloads/releases/latest). Run it on Windows while Dota 2 is in borderless window or windowed mode. Restart Dota 2 once after the first run so it loads the overlay integration.

New versions appear on the [Releases page](https://github.com/vshtykhnov/outdraft-downloads/releases). Use the **Check updates** link in the overlay and replace the old executable after closing it. The app requires an internet connection to its API.

This repository contains downloads only. The application source and API are kept in a separate private repository. GitHub's automatically generated source archives on each release contain only the files in this downloads repository.
