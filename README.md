# Outdraft for Windows

Download the latest [Outdraft.exe](https://github.com/vshtykhnov/outdraft-downloads/releases/latest/download/Outdraft.exe) from GitHub Releases. Current release: [v0.1.1](https://github.com/vshtykhnov/outdraft-downloads/releases/tag/v0.1.1).

Run it on Windows while Dota 2 is in borderless window or windowed mode. Restart Dota 2 once after the first run so it loads the overlay integration.

To update, close Outdraft and replace the old executable with the latest download. The app checks for new releases and opens the download page. An internet connection is required to reach the API.

This repository contains downloads only. The application source and API are kept in a separate private repository. GitHub's automatically generated source archives for each release contain only the files in this downloads repository.
